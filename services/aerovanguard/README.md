# AeroVanguard v4.8 — civilian research edition

Live tool: https://maxjimtech.github.io/services/aerovanguard/

Standalone civilian full-function HTML: maxjim_tech_aerovanguard_3d.html (identical to index.html).

This public release contains six civilian survey, inspection, logistics and research profiles: JOUAV CW-30E, Wingcopter 198, DJI Matrice 350 RTK, DJI FlyCart 30, Freefly Alta X and Airbus Zephyr S. The original supplied file is preserved locally and is not included in this repository.

The interface displays: 完整版本 請洽 肇祥企業社 MaxJim Tech Inc.
The full-version link has the stable DOM id FullVersionLink and currently points to this standalone civilian HTML in GitHub. Replace its href when a separate approved civilian full-version destination is available. No military/weapon profile version is hosted here.

Layout changes: wrapping header and model selector, readable mathematical labels, separate camera/legend/PFD layout, mobile dialog scrolling, accessible close buttons and form labels, canvas ResizeObserver, fullscreen and website navigation.

JSON, CSV and watermarked PNG exports were downloaded in browser checks. These are interface/download checks, not verification of aerodynamic or structural accuracy, certification or full accessibility compliance. Numeric outputs are estimates from the supplied solver.
