# CNC Studio 瀏覽器版 v0.5.0

線上入口：https://maxjimtech.github.io/services/cnc-studio/

本版使用 HTML、CSS、JavaScript 模組及 OpenCascade WebAssembly，可在瀏覽器匯入 STEP 或 FANUC 風格 G-code，生成可檢視的刀路與近似素材除料結果。正常使用不需在電腦安裝後端服務；STEP 與 G-code 檔案由瀏覽器本機解析。

## 直接操作

1. 由「匯入來源」選擇「G-code → 素材除料」，讀取 .nc、.tap、.gcode 或 .txt，或按「載入除料模擬範例」。
2. 選擇虛擬 CNC 母機、工件材料（AL6061／S45C／SUS304），輸入素材 X、Y、Z 尺寸、G54 頂面 Z、模擬網格精度（0.35–5 mm），及第一段刀路**之前**的假設刀尖 G54 X/Y/Z 座標。素材在 G54 X0–X長、Y0–Y寬；若實際原點不同，需先轉換座標。
3. 將未明確換刀的預設刀具選為刀庫對應項目。匯入程式若含 T/M06，刀具必須在內建刀庫，否則停止解析。
4. 按「解析 G-code 並模擬除料」，由進度條查看 3D／XY／XZ／YZ 的加工過程，也可按「檢視除料完成後工件」。
5. 可下載已解析的原始 G-code、計算工作單 JSON 和近似的加工後 STL 表面。**匯入原始 G-code 只提供檢視，並非重新認證或已安全校正的程式。**

STEP 模式可匯入單一有效 STEP 實體（≤50 MB），以規則辨識 2.5D 頂面開放特徵並建立面銑、口袋／配對鑽孔工程草稿。另可選擇球頭銑刀對符合高度場限制的凹弧曲面進行三軸往復雕刻；加工前需人工確認已預粗加工。STEP 建立刀路後可再按「以目前刀路計算素材除料與完工件」。

## 解析和計算範圍

- G-code：檔案 ≤3 MB、≤120,000 行、≤80,000 段移動。辨識 G00/G01、G20/G21、G90/G91、G17、G54、G40、G43/G49、G80、G94、S/F、T/M06 等限定指令。G02/G03、G28/G53、固定循環、巨集、子程式、非 XYZ 軸、補正動作及未知指令直接拒絕；目前僅支援三軸直線切削。G43/H 僅辨識並警告，**不計算刀長補正值**。
- 素材：XY 高度網格，最大 35,000 格（每方向最多 180 格）；刀尖沿 G01 路徑掃掠，模擬平底銑刀、球刀及鑽尖近似輪廓。累積除料體積、剩餘素材體積、估計移除質量及 61 個等時間間隔影格。密度以一般標稱值估算。
- G00 快移不除料。依刀具半徑擴張素材包絡後截取快速刀路，再以網格近似偵測可能接觸；這是碰撞**警示**，無法取代完整機台、刀柄、刀桿、虎鉗與夾治具干涉分析。
- 3D 素材顯示為降採樣外觀；XY 與 XZ／YZ 剖面來自高度格網。STL 代表近似「剩餘素材」，非原 STEP 精度、非精確 BREP；部分複雜高度場可能仍需專業網格修補。

**重要限制：** 高度場只適用 +Z 垂直進刀可接近的幾何，不支援倒扣、側孔、封閉內腔、五軸、實際刀具切削負載、工件偏移量查證、機台運動學或真正控制器驗證。時間不包含換刀、停機、加減速。所產 FANUC 為工程審查草稿；實機上機前須專業 CAM 校驗、選定真實母機與刀補、檢查原點／座標系、夾治具／干涉及空跑，不能直接用於製造放行。

## MiniLM / Laya

加工策略預設由幾何與確定性規則決策，無須 Laya。可選擇實驗性的 MiniLM 語意相似度排序（僅 2.5D，要求人工覆核）；首次使用須從 jsDelivr/Hugging Face 取得函式庫及模型。已完成 7 項離線介面測試，**尚未驗證正式網路上的真實 ONNX 推論結果或加工領域校準**；失敗時可取消選用後以規則模式繼續。此功能不修改電腦的中央 Laya 開關。

## 部署與版本驗證

本程式以 GitHub Pages HTTPS 方式部署。為符合 ES modules、Web Worker、WASM 和 fetch 的規則，下載後需用本地 HTTP 靜態伺服器開啟，不能以 file:// 直接雙擊 index.html。OpenCascade 核心與其授權資訊在 vendor/，曲面與平面範例 STEP 及除料範例 NC 在 examples/，更早的示範版本保留在 legacy-0.1.1/。

本版本地驗證：CAM 14、STEP 幾何 7、MiniLM 離線 7、曲面 12、G-code／除料／STL 16、Chrome 真實 UI 12，合計 **68 項通過**、Chrome Console 錯誤 **0**。上述測試驗證軟體支援範圍與視覺流程，不是實機量測或刀路製造安全保證。
