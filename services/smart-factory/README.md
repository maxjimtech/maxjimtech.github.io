# MAXJIM 3D 智慧工廠規劃系統 v2.0

網站：https://maxjimtech.github.io/services/smart-factory/

中英雙語產線與廠房配置工具；支援全視窗、全螢幕、設備配置、模擬、JSON、CSV、SVG、PNG。

原始附件為 Installer Suite；本資料夾只部署瀏覽器版與 PWA 資源，未執行或發布桌面安裝腳本。保留原有模擬與計算功能；網站版增加全螢幕、工具盒與官網連結，BOM 預設收合。PWA scope 限於此目錄，快取清理只處理此工具的版本。離線使用需先成功載入並快取 CDN，未完成離線實測。

範例：sample_projects/CNC_Robot_Cell_Project.json，可由「下載範例」取得，再以「載入專案」開啟。

產線、功率與安全提示為原程式的規劃估算；本站部署驗證不等於工程合格認證。
