# MAXJIM 工具盒 3D 佈局規劃器 v3.2

獨立 GitHub Pages 版本；直接填滿瀏覽器視窗。點「全螢幕操作」，按 Esc 或「離開全螢幕」還原。BOM 面板預設收起，可由「工具 BOM 清單」展開。

沿用原版工具功能，增加全螢幕、返回官網與視窗版面。配置只在瀏覽器中處理，使用者可匯出 JSON、CSV、SVG、PNG。

實際附帶 2 份 JSON 範本：kit_24_socket.json、kit_46_auto.json；工具內有 4 種組套選項。依賴 Tailwind 3.4.17、Three.js r128 與同版本 OrbitControls CDN。
